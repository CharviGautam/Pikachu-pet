# PUPPY — UI/UX & Art Bible

> The puppy is the UI. Most "design" here is character art, motion feel, FX and audio; the only conventional UI is the small settings window, speech bubbles and native menus.
> Identity is defined by `assets/reference/master_reference.png` + `assets/spec/character.bible.json`. This document never overrides them.

## 1. Design philosophy

**Cute first, lightweight second, features third.** Soft, warm, pastel, round. Motion is springy but small; nothing flashes, nothing nags. Every visual element should look like it belongs to the same sticker sheet: same outline weight, same palette, same softness. If something cannot be made in that style, it is drawn by code from palette tokens, never generated ad hoc.

## 2. Palette (derived, not invented)

`tools/extract_palette.py` reads `assets/approved/master/master_front.png`, clusters the opaque pixels (k-means, k = 8, in Lab), names the clusters by role, and writes `assets/spec/palette.json`. `gen_from_spec.py` emits from it: `src/generated/palette.ts` and `src/shared/palette.css` (CSS custom properties). **Do not hard-code hex values in TypeScript, CSS or Python outside `palette.json`.**

## 3. Character art rules (enforced by prompts and QA)

- Cartoon chibi, soft cel-shading, uniform warm-brown outline ≈ 3 px at 384 px. No realistic fur texture.
- Head ≈ 55% of body height; tiny paws; big fluffy tail; floppy ears.
- Identity constants that never change between frames: eye shape/colour/highlight layout, ear shape, nose, cream markings, outline weight.
- **Facial vocabulary:** happy = eyes open with sparkle highlights; bliss/petting/blink = closed as curved arcs `∪`; surprised = tiny pupils, round mouth; sad = ears drooped, glossy eyes looking down; sleepy = half-lidded.
- **Not generated by the model (code draws these):** hearts, Zzz, sparkles, "!" / "?", sweat drop, dizzy stars, dust puffs, speech bubbles, ground shadow. This keeps them palette-perfect and lets FX scale/animate freely.
- No text, watermark, ground, shadow, or extra props inside character frames. Props (ball, bone, TV, bed) are separate single images generated with the same style lock (V2).

## 4. Motion principles (implemented in code, not extra frames)

| Effect | Spec |
|---|---|
| Idle breathing | Scale Y `1 → 1.012 → 1` over 2.4 s about the baseline anchor (only during `idle_sit` holds) |
| Hop / click reaction | Sprite offsets y by `−10·scale` then back with ease-out-quad, 220 ms; landing squash `scaleX 1.08, scaleY 0.92` for 90 ms |
| Fall / drop | Gravity 2400 px/s²; on impact squash for 120 ms; secondary bounce 25% height once |
| Pick-up | On drag start, scale 1.05 for 100 ms |
| Crossfade (camera change) | 120 ms linear alpha blend, no scaling |
| Walk bob | None (bob is in the frames) |
| Look transition | Hard cut between `look_*` frames with hysteresis (03 → 2.1) |
| Easing | `easeOutQuad` for pops, `easeInOutSine` for sways. No bounce libraries |

`reduceMotion`: disables hop/squash/bounce effects (keeps the animation frames and crossfades).

## 5. FX specifications (`src/pet/fx/*`)

Particles are pooled (max 48 live), drawn on the pet canvas above the sprite, and disappear within 1.5 s. Sizes are logical px × scale.

| FX | Spawn | Motion | Look |
|---|---|---|---|
| Heart (petting) | 5–7 per burst, x ∈ head ±30, y = head top | rise 60 px/s, sway `sin` amplitude 8 px, life 1200 ms, fade last 40% | vector heart 10–16 px, fill `--fx-heart`, highlight `--fx-heart-light`, outline 1.5 px `--pup-outline` at 60% alpha |
| Big heart (kiss) | 1 big (24 px) at kiss peak + 3 small | rise 50 px/s, life 1400 ms, slight scale pulse 1→1.15 | same |
| Zzz | every 1400 ms while `sleep_loop` | rise 24 px/s to upper-right, letters `z`,`Z`,`Z` growing 10→16 px, life 2000 ms | rounded bold font stack, fill `--fx-zzz` |
| Sparkle | happy/excited, 2–3 | twinkle scale 0→1→0 in 600 ms | 4-point star `--fx-spark` |
| "!" | on `surprised` frame 0 | pop scale 0→1.2→1 over 150 ms, life 800 ms | `--pup-outline` outlined, fill `--fx-spark` |
| "?" | on `curious` frame 0 | as "!" | same |
| Dizzy stars | `trip` frame 3 | 3 stars orbit head, life 900 ms | `--fx-spark` |
| Dust puff | `trip` frame 2, run stop, landing | 3 circles expand 6→14 px while fading, life 400 ms | `--shadow` colour at 40% |
| Ground shadow | always under puppy | ellipse `w = 0.55·display width`, `h = 0.12·w`, at baseline; shrinks/blurs with height above ground | `--shadow` |

Fonts: system rounded stack only — `ui-rounded, "SF Pro Rounded", "Nunito", "Segoe UI Variable", system-ui, sans-serif`. Nothing is downloaded.

## 6. Speech bubble spec (`fx/bubble.ts`)

Drawn in canvas above the head, inside the window's top 64 px band. Max width `224·scale`, font 13 px × scale (min 11 px), line-height 1.25, max 2 lines. Padding `8×12`. Fill `--bubble-bg`, 2 px border `--pup-outline`, corner radius 14 px, 8 px tail pointing at the head, soft 0 2 0 shadow at 10% alpha. Pop-in scale 0.85→1 over 200 ms, hold 3500 ms, fade 200 ms. Text colour `--bubble-text`. If the window's top edge is within 8 px of the top of the work area, skip the bubble (never draw it clipped or below the head).

## 7. Settings window design system

Purpose: unobtrusive, native-feeling, fully keyboard-accessible. Follows `prefers-color-scheme`. Base spacing 4 px; scale 4/8/12/16/24/32. Radius 8 (controls) / 12 (cards). Font 14 px/1.45 system UI stack; section titles 13 px 600 uppercase letter-spacing 0.04em; window title 18 px 600.

CSS variables (generate into `src/shared/palette.css`; palette tokens above are merged in):

```css
:root {
  --ui-bg: #FBF7F0;  --ui-surface: #FFFFFF;  --ui-text: #3C2A1E;  --ui-muted: #7C6A5C;
  --ui-accent: #E9A23B;  --ui-accent-contrast: #2B1B0E;  --ui-border: #E6DACB;  --ui-danger: #C0473B;
  --ui-focus: #2F6FE4;  --radius-control: 8px;  --radius-card: 12px;
}
@media (prefers-color-scheme: dark) {
  :root { --ui-bg: #1F1712; --ui-surface: #2A2019; --ui-text: #F4E9DC; --ui-muted: #B5A594;
          --ui-accent: #F0B357; --ui-accent-contrast: #24160A; --ui-border: #41332A; --ui-danger: #E07A6E; --ui-focus: #7FA8FF; }
}
```

Components (exact CSS in `src/settings/settings.css`; all controls have default/hover/focus/disabled states):

| Component | Spec |
|---|---|
| Card (section) | `background: var(--ui-surface); border:1px solid var(--ui-border); border-radius: var(--radius-card); padding:16px; margin-bottom:12px` |
| Row | grid `1fr auto`, min-height 40 px, `gap:12px`, label left, control right, optional muted helper text below label (12 px) |
| Toggle | 40×24 track, 20 px thumb; on = `--ui-accent`; `role="switch"`, `aria-checked`; Space/Enter toggles; disabled opacity .5 |
| Slider | native `input[type=range]` styled with accent track; numeric readout right-aligned tabular-nums; `aria-valuetext` includes unit |
| Select | native `<select>` styled: height 32, padding 0 10, border `--ui-border`, radius 8 |
| Segmented control | radio group rendered as 3 buttons, selected = accent fill; arrow keys move |
| Text input | height 32, padding 0 10, border `--ui-border`; invalid = border `--ui-danger` + 12 px error text with `aria-describedby` |
| Button | primary (accent), secondary (border only), danger-ghost; height 32; focus ring `2px solid var(--ui-focus)` offset 2 |
| "Saved" tick | 12 px muted text, fades in/out 1.2 s, `aria-live="polite"` |

Accessibility: WCAG 2.1 AA (text contrast ≥ 4.5:1 — verify light and dark pairs in a unit test using the tokens), visible focus everywhere, logical tab order, no colour-only meaning, respects OS reduced-motion for UI transitions. The pet window itself is decorative: `aria-hidden`, no focusable elements.

Responsive: fixed 480 px width; content scrolls vertically if the OS font scale makes it taller than the window.

## 8. Audio design

Tiny, soft, rounded sounds; never loud; each has a cooldown and random ±6% pitch variation. Master volume default 0.5.

| SoundId | Trigger | Synth placeholder (WebAudio) | Cooldown |
|---|---|---|---|
| `bark` | `bark` frame 0 | two short triangle blips 520→380 Hz, 90 ms each, low-pass 2 kHz | 4 s |
| `yip` | `excited` start, chase start | one triangle blip 700→900 Hz, 70 ms | 3 s |
| `happy` | `happy` loop start | rising two-note sine chirp 660→880 Hz, 120 ms | 6 s |
| `purr` | petting start | 250 ms band-limited noise with 25 Hz amplitude wobble, gain 0.15 | 3 s |
| `kiss` | `kiss` frame 2 | short noise "mwah" burst 60 ms + sine drop 900→500 Hz | 2 s |
| `sneeze` | `sneeze` frame 2 | noise burst 120 ms, band-pass sweep 2.5→1 kHz | 10 s |
| `yawn` | `yawn` frame 2 | sine glide 500→300 Hz, 500 ms, soft attack | 10 s |
| `whimper` | `sad` enter | sine glide 600→420 Hz, 300 ms, vibrato | 10 s |
| `pop` | bubble show | sine blip 800 Hz 40 ms | 1 s |
| `thud` | landing after fall | sine 90 Hz 80 ms, gain 0.2 | 500 ms |

Real recordings (CC0) may be dropped into `public/assets/audio/<SoundId>.mp3` later; `audio.manifest.json` picks them up automatically. Sleep: no sound. Hidden/sleeping: `AudioContext.suspend()`.

## 9. Tray icon and app icon

Tray: monochrome puppy-head silhouette (template image on macOS), 16/32 px + @2x. App icon: cropped puppy face from `master_front.png` on the fur-cream circle, exported once to `assets/approved/app_icon_source.png` (1024×1024, transparent), then `npm run tauri icon assets/approved/app_icon_source.png` generates the platform set into `src-tauri/icons/`.
